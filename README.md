# Sales Data Analysis

## Aim
To analyze product sales and calculate total revenue using R programming.

## Description
This project contains product quantity and price information. R calculates revenue for each product and identifies the product generating the highest revenue.

## Technologies Used
- R Programming
- Data Frames
- Arithmetic Operations

## Features
- Calculates product revenue
- Calculates total revenue
- Calculates total units sold
- Finds the best revenue-generating product

## How to Run
1. Open `04_Sales_Data_Analysis.R`.
2. Run it using RStudio or VS Code.
3. Check the output in the R console.

## Result
The program successfully analyzes sales data and identifies the product with the highest revenue.
